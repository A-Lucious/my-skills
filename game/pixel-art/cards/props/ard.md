# Props: Aseprite Rough Draft (ard)

For the standard 3D route, import the exact protected Shader base, then execute the [constrained source-color cleanup](../../styles/parchment-fantasy/PIXEL-SHADER.md#4-constrained-correction-through-aseprite-mcp) on `draft` before artistic refinement; preserve the hidden locked `base-ref`.

Focuses on base import, palette ramp mapping, landmark exaggeration, and value mass consolidation.

## 1. Import & Layer Discipline
- Import the native PNG from Phase 3 directly via Aseprite MCP into a new `.aseprite` file.
- Keep the untouched imported base as a locked reference layer (`base-ref`), and duplicate it into the active working layer (`draft`).

## 2. Palette Ramp Mapping
- Map raw base pixels to fixed color families defined in `palette.json`:
  - Wood components -> `earth` or `leather` working ramps.
  - Metal bands & latches -> `gold` (brass) or `neutral`/`blue` (iron/steel).
  - Glass & fluid -> `ruby`, `teal`, or `emerald` ramp sets.
- Merge accidental intermediate shades generated by anti-aliasing into strict 3-to-5 step tonal ramps.

## 3. Landmark Exaggeration
- Strengthen key functional features that appear faint or fragile in the 3D base:
  - Enlarge latch keyholes or lock hooks to 2x2 or 2x3 solid pixel blocks.
  - Thicken thin handles or strap buckles by 1 pixel where needed to ensure instant read.
  - Clean container mouth openings, ensuring a crisp separation between external rim and dark interior.

## 4. Value Mass Consolidation
- Unify fragmented shading on planar surfaces into clear illuminated, turning, and shadowed clusters.
- Preserve ground and cavity cast shadows as defined in 3D guidance.
