# Feature Card: Flat UI & Decorative Elements (Track B)

> This card is a **sub-strategy inside Baseline A (Production)**: it lets flat decorations skip the
> Blender phases. It is not "Baseline B" — Baseline B is the
> [Agent Pure-Draw Baseline](pure_draw.md). See [Baseline Selection](../../specs/baselines.md).

Focuses on pure 2D silhouette blockout, parchment frame rhythm, and semantic icons.

## 1. Pure 2D Blockout (Track B Strategy 1)
- For flat decorative assets (scroll ribbons, parchment UI frames, heraldic banners, skill icons), 3D modeling may be explicitly bypassed.
- Begin directly in Aseprite with **Silhouette Blockout**: sculpt hand-drawn curves, torn parchment corners, and dynamic scrolls using solid color blocks.

## 2. Parchment Frames & Borders
- Emphasize organic asymmetry: stepped corners, weathered edge chips, and margin breathing room.
- Use layered parchment tones (`parchment`, `paper`, `leather` families) to indicate paper thickness without artificial 3D bevels.

## 3. Symbolic & Semantic Icons
- Prioritize iconic silhouette clarity and negative space over complex internal shading.
- Keep color counts minimal (typically 2–4 tones per icon) to maintain legibility at small HUD scales (16x16, 24x24, 32x32).
