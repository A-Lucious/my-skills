## 文档定位与原则

1. **指导生产实操**：文档基于真实任务与真实 MCP 调用（Blender MCP、Aseprite MCP）记录，避免脱离实际的纯理论阐述。
2. **规范边界明确**：明确各管线触发条件（如 3D 路线 vs 生图模型条件分支）、调色板限制与构图红线。
3. **保留客观对比**：通过对比真实提示词、输入媒介与输出产物，展示不同技术路径对最终像素艺术风格的塑造机制。
