## 按需取用

先在来源页看预览并确认当前协议。下载选中的文件和授权说明到项目 `Test Workspace/asset-cache/`，下载前检查空间，清理最久未使用的可丢弃缓存，使缓存总量保持在 **50 MiB** 以内。若只能下载整包，确认其符合预算，提取需要的文件后立即删除临时归档及未选文件；超过预算时改用单文件来源。

工作副本放在 `Test Workspace/<task-id>/references/`，记录来源、作者、协议和修改说明；通过项目 Aseprite MCP 改造及正式导出。交付后清理下载缓存和不再需要的参考副本，仅保留实际采用的文件、必要授权记录和交付物。50 MiB 是取用流程的预算，没有常驻下载或自动清理服务。

使用 CC BY 3.0 图标须保留对应作者署名、来源及协议链接，并说明修改。具体授权记录见 [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md)；已有远程文件校验信息见 [index.json](index.json)。下载文件、归档和预览均不提交到此索引库。
