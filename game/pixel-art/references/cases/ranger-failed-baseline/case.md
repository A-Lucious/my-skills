# 游侠画像：失败基线案例

- 归档状态：**失败基线案例**。
- 归档定位：**“无参考照片，无生图”下使用 Blender 建模的失败案例**。
- 失败原因：
  1. 人物模型：无参考下手工建立的上游 3D 面部体块过于概括生硬，眉弓、眼眶与下颌骨骼结构缺乏自然说服力。
  2. 面部表情：五官联动不自然，半垂眼睑与嘴角显得木讷、疲惫。
  3. 构图人脸占比不足：头部过小，披风、胸口与装饰占据大量空间，导致 64×64 画布中分配给五官神态的像素严重不足。
- 对照价值：确立了人物画像必须“人脸为主体特写”的构图标准，以及在缺乏可靠人物模型时避免纯 3D 盲建。
