# 兜帽青年人物画像（头颈大占比特写）

- 规格：原生 64×64 RGBA，parchment-fantasy 风格。
- 构图定位：头部与颈部占据画面主要面积，顶部边缘预留微量发顶空间，底部仅保留少许斗篷领口，免躯干与大面积服饰挤占像素预算。
- 流程路线：授权生图来源路线 → 平滑人物 Pixel Shader（Anisotropic Kuwahara 4.0 + 调色板映射）→ Aseprite。
- 状态：用户已明确认可构图比例（“这个占比可以，不需要再精修了”）。
